## 環境
1. VS2013環境  
boost : version 1_58_0  
ターゲットプラットフォーム : WIN32
2. VS2017  環境  
boost : version 1_73_0  
ターゲットプラットフォーム: x64
## 環境構築
1. [Kinect SDK](https://www.microsoft.com/en-us/download/details.aspx?id=44561)のインストール
2. boostの設定
    - boost1_58_0  
    bullに中のビルド済みboost1_58_0のフォルダをローカルにコピーしてシステム環境変数に**BOOST_DIR**として追加
    - boost1_73_0  
    bullにあるboost1_73_0のzipファイルをローカルに展開してシステム環境変数に**BOOST_DIR_173**として追加
3. Visual Studio
    - 2013  
    bullにあるインストーラとライセンスからインストール
    - 2017  
    [ダウンロードページ](https://visualstudio.microsoft.com/ja/vs/older-downloads/)からVisual Studio Community 2017をインストール  
    ログインアカウントは研究室のMicrosoftアカウント(vmlab_2020@outlook.jp)を使えばよい
4. このリポジトリをクローン
5. 不足しているファイルをコピー  
※.gitignoreによって*.dllはgitの管理下にないのでbullからコピーする必要がある。  
    - bullにあるディレクトリを`(SolutionDir)\Library\`にコピー
    - bullのffmpegの設定フォルダの中のdllファイルを全部`(SolutionDir)/x64/Release`の中にコピー  
    ※`(SolutionDir)/x64/Release`は一度ビルドに失敗すると生成されているはず  
    このとき`Release\x64`（VS 2013なら`Release\WIN32`）で動作させる必要がある
6. 必要な動画ファイルをコピー（ほかのマシンの中を探せば動画ファイルがあるはず）  
※読み込む動画ファイルは*Media.cpp:68*あたりの動画ファイルへのパスから変更できる
## 実行方法
1. Kinect Serverを立ち上げる（Kinect Serverのプログラムは`https://github.com/visual-media-lab/3D_Kinect_Tracking_Server`をクローンするでも良いし、bullからコピーするでもよい。GitHubからのクローンで動作するかは確認していないのでbullからコピーするのが確実。）
2. プログラムを実行
3. 基板のスイッチを切り替えてバックライトを時分割モードに切り替え（この手順はいつでもいい）
## 主なキー入力の説明
| 入力キー | 動作 |
| --- | --- |
| h | ヘッドトラッキングのON/OFF切り替え |
| m | 動画モードへ移動 |
| shift + m | 静止画モードへ移行 |
| t | 時分割モードのON/OFF切り替え（本番環境下では時分割モードOFFだと立体視不可）|
| q, w, e, r | フレーム0, 1, 2, 3を描画（本番環境下では使わない） |
| 1 | 静止画モード：静止画1に切り替え, 動画モード：Teapotに切り替え |
| 2 | 静止画モード：静止画2に切り替え, 動画モード：動画表示 |
| 0, 3 ~ 7 | 静止画を切り替え（動画モードでは何も動作しない） |
| shift + B | 右目の描画OFF |
| b | 右目の描画ON |
| shift + v | 左目の描画OFF |
| v | 左目の描画ON |
| shift + ;, - | 動画モードのスケール変更 |
| [ | 幅パラメータのインクリメント |
| ] | 幅パラメータのデクリメント |
| k | フレームの調整（バックライトとの同期がずれたときに使用) |
| shift + k | 現在の観測者のz座標と幅パラメータを出力（パラメータ調整用） |
